Over the past few days I have tested the exported fine-tuned MobileNetV1-SSD model and started a new project: creating a new Follow Line exercise based on [reinforcement learning](https://en.wikipedia.org/wiki/Reinforcement_learning) (RL).

## Testing MobileNetV1-SSD in Visual Object Detection

As I did with the End-to-End Visual Control exercise, I exported the model to .onnx and imported it into the Visual Object Detection exercise in RoboticsAcademy. At first I ran into problems with Pylint and OpenCV: Pylint flagged OpenCV functions as no-member even though they exist.

![Pylint error with OpenCV](Error_Pylint_Opencv.png)

After disabling the no-member check and adapting the code from the previous exercise, I was able to test the model correctly.

## Studying Gymnasium and Stable Baselines3

This week I have been studying [Gymnasium](https://gymnasium.farama.org/index.html). I worked through its "hello world" example and the Blackjack environment, and I also read the documentation of [Stable Baselines3](https://stable-baselines3.readthedocs.io/en/master/).

I will need these libraries to apply RL algorithms in the new Follow Line exercise. In the coming days I will install [Gazebo Jetty](https://gazebosim.org/docs/latest/release_notes/) and build an example combining RL and [ROS](https://www.ros.org/).
