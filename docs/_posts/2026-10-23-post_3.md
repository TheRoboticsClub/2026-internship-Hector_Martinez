## Testing YOLO11n in Visual Object Detection

To finish this activity, I fine-tuned a YOLO11n model and exported it to ONNX.

To work with the same dataset used for the MobileNet model, I first had to convert the Open Images CSV annotations (corner coordinates, one row per box) into YOLO format, as required by the [Ultralytics detection documentation](https://docs.ultralytics.com/datasets/detect). This format uses one `.txt` file per image, with one line per object: `class x_center y_center width height`, normalized between 0 and 1.

**CSV to .txt parser**

```python
import pandas as pd
import os

def convert_split(csv_path, labels_out_dir):
    os.makedirs(labels_out_dir, exist_ok=True)
    df = pd.read_csv(csv_path)
    for image_id, group in df.groupby("ImageID"):
        lines = []
        for _, row in group.iterrows():
            x_center = (row["XMin"] + row["XMax"]) / 2
            y_center = (row["YMin"] + row["YMax"]) / 2
            width = row["XMax"] - row["XMin"]
            height = row["YMax"] - row["YMin"]
            lines.append(f"0 {x_center:.6f} {y_center:.6f} {width:.6f} {height:.6f}")
        with open(os.path.join(labels_out_dir, f"{image_id}.txt"), "w") as f:
            f.write("\n".join(lines))

src = "/home/hectormc/IA_Jderobot/dataset-person"
dst = "/home/hectormc/IA_Jderobot/dataset-person"

convert_split(f"{src}/sub-train-annotations-bbox.csv", f"{dst}/labels/train")
convert_split(f"{src}/sub-validation-annotations-bbox.csv", f"{dst}/labels/val")
convert_split(f"{src}/sub-test-annotations-bbox.csv", f"{dst}/labels/test")
```
